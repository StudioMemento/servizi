VERCEL
Estrarre lo ZIP e caricare il CONTENUTO nella root del repository.
index.html, package.json, build.mjs, vercel.json e assets/ devono essere
allo stesso livello. Non caricare una cartella contenitore aggiuntiva.

Framework Preset: Other
Root Directory: vuota (root del repository)
Build Command: npm run build
Output Directory: dist
Install Command: vuoto

La build copia il sito statico in dist/, senza dipendenze esterne.
Verifica locale: npm run build
Questo pacchetto non esegue automaticamente un deploy su Vercel.

Le route rimangono hash (#bundle/b-lancio, #servizio/sito).
Le CTA aprono https://mementostudio.it/start fuori dall'embed.
Il fondo pagina rimane trasparente nell'iframe: per il blur esterno
consultare INTEGRAZIONE_NAV.txt. La Nav Framer live non viene modificata.
