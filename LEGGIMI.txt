VERCEL

index.html, package.json, build.mjs, vercel.json e assets/ devono essere
allo stesso livello. Non aggiungere una cartella contenitore.

Framework Preset: Other
Root Directory: vuota (root del repository)
Build Command: npm run build
Output Directory: dist
Install Command: vuoto

La build copia il sito statico in dist/, senza dipendenze esterne.
Verifica locale: npm run build
Questo pacchetto non esegue automaticamente un deploy su Vercel.
