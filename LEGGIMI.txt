MEMENTO — SERVIZI V29
Polish completo: 44 servizi e 6 bundle, 200 tavole commerciali.

VERCEL
Estrarre lo ZIP e caricare il CONTENUTO nella root del repository.
index.html, package.json, build.mjs, vercel.json e assets/ devono essere
allo stesso livello. Non caricare la cartella contenitore dello ZIP.

Impostazioni progetto:
  Framework Preset: Other
  Root Directory: vuota (root del repository)
  Build Command: npm run build
  Output Directory: dist
  Install Command: vuoto

La build copia il sito statico in dist/. Nessuna dipendenza esterna,
variabile d'ambiente o database richiesto. Per verificarla localmente:
  npm run build

Questo ZIP non esegue un deploy su Vercel.
Le route usano hash, per esempio #bundle/b-lancio o #servizio/sito.
Le CTA aprono https://mementostudio.it/start fuori dall'embed.

CONTENUTI

Titoli, testi, bordi e blending sono nel codice. Foto pulite e responsive.

Gli originali dei 44 servizi restano nell'archivio V28 già consegnato.
